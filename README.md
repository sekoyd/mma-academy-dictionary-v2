# MMA Academy Dictionary v2

An independent, source-led retail media dictionary built for local review from
`MMA_Dictionary_Master_Glossary_v1.xlsx`.

## Run locally

```bash
python3 -m http.server 8735 --bind 127.0.0.1 --directory site
```

Open <http://localhost:8735/>.

## Source fidelity

- The site contains all 102 source records in spreadsheet order.
- The duplicate `Viewability` entries are retained.
- Missing definitions are labelled rather than invented.
- The original workbook remains unchanged in `source/`.

## Brand assets

The supplied MMA Academy logos are retained without geometric or color edits.
Söhne and Tiempos are bundled for local review. Confirm the applicable webfont
licence before public deployment or external distribution.
